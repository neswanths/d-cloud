Calls
AdminRequest::AttachAppInterface
and adds another app
interface

Usage: hc sandbox call add-app-ws [OPTIONS] [PORT]

Arguments:
  [PORT]
          Optional port
          number. Defaults
          to assigned by OS

Options:
      --allowed-origins <ALLOWED_ORIGINS>
          Optional allowed
          origins.
          
          This should be a
          comma separated
          list of origins,
          or `*` to allow
          any origin. For
          example:
          `http://localhost:3000,http://localhost:3001`
          
          If not provided,
          defaults to `*`
          which allows any
          origin.
          
          [default: *]

      --installed-app-id <INSTALLED_APP_ID>
          Optional app id to
          restrict this
          interface to.
          
          If provided then
          only apps with an
          authentication
          token issued to
          the same app id
          will be allowed to
          connect to this
          interface.

  -h, --help
          Print help (see a
          summary with '-h')
